- 검증된 필드와 필드별 상태
- 보류 사유와 전체 상태
- source hash
- 프롬프트 SHA-256

비교에는 유료 API 호출이나 DB 결과 재저장이 필요하지 않았다. 결과는 ready 3건 / partial 2건으로 유지된다.

### AI 리서치 화면의 재점검 수정

1. **계정 전환 중 늦게 도착한 답변**: 요청 시작 당시의 계정 버전을 함께 전달한다. 계정이 바뀐 답변과 오류 메시지는 새 계정의 대화에 저장하지 않는다.
2. **계정별 대화 즉시 전환**: 현재 사용자 변경을 먼저 반영한 뒤 계정 버전을 갱신하며, 대화 저장소는 동기적으로 새 계정의 기록을 읽는다.
3. **남아 있던 구형 관리자 토큰 입력창**: AI 리서치 화면에서 직접 전역 관리자 토큰을 바꾸던 입력창을 제거했다. 데이터 현황의 인증된 관리자 연결을 사용하며, 외부 문서 수집 UI도 관리자 연결 후 표시한다.
4. **가독성**: 길게 압축되어 있던 AI 질문 전송 흐름을 단계별 코드로 풀어 정리했다.

새 회귀 테스트는 이전 계정의 늦은 답변 차단, 계정별 기록 복원, 소유자 없는 기존 대화의 관리자 전용 로드를 확인한다.
