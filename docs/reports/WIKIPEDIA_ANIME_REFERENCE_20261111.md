# 위키백과 애니메이션 작품 사전 추가

2026-11-11, 한국어 위키백과의 가나다·알파벳 하위 목록 15개를 수집했다.

- 중복 정리 제목 632개, 일본어 언어 연결이 있는 제목 504개.
- 기존 사전과 중복되는 제목·별칭을 우선 제외해 실행 사전에 작품 587개 추가.
- 최종 실행 사전 작품 수 1,133개. 기존 캐릭터·피규어 종류 규칙 유지.
- 전체 제목이 일치하는 검색과 작품 필터는 확인된 별칭으로 확장한다.
- 분류 워커는 추가 사전을 사용하며 기존 상품 DB의 작품 분류 일괄 재처리는 하지 않았다.
- 원본 목록에는 영화·OVA와 표기 변형도 있다. TV 작품의 완전한 목록으로 보증하지 않는다.
- 원문 HTML, 고정 문서 버전, 제목별 출처, SHA-256은 `data/reference/wikipedia_anime/`에 보관.
- 실행 사본은 `backend/app/services/classification_wikipedia_anime.json`.
- 백엔드 전체 테스트 183개 통과, PostgreSQL 등 별도 환경이 필요한 테스트 18개 건너뜀.
- 프로젝트 구조 검사 통과. 백엔드 이미지 빌드 및 서비스 재생성 완료.

갱신 도구: `python scripts/import_wikipedia_anime.py --refresh`.
DB 쓰기나 모델 호출 없이 공개 위키 API를 읽고 참조 파일을 생성한다.
출처·이용 조건은 루트 `THIRD_PARTY_NOTICES.md`를 따른다.
