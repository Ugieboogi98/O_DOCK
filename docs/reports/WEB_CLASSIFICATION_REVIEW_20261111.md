남은 상품·필드 7,536건을 6,356개 확인 그룹으로 묶었다. 필드별 상품 수이므로 같은 상품이 여러 문서에 나타날 수 있다. 상품 구성이 서로 다르면 같은 그룹도 일괄 승인하지 않아야 한다. 작품만 명시된 상품에서 캐릭터를 추측하거나, PVC·일반 피규어 표기만으로 스케일·가동 여부를 확정하지 않았다.

## 근거와 적용

- 검증 사전: 작품 388개, 캐릭터 195개, 제품군 규칙 20개. 별칭은 별도로 포함한다.
- [반프레스토 공식 브랜드](https://bsp-prize.jp/brand/), [메가하우스 룩업](https://www.megahobby.jp/event/lookup/), [우마무스메 공식 캐릭터](https://umamusume.jp/character/), [산리오 공식 캐릭터](https://www.sanrio.co.jp/characters/) 등의 자료와 위키의 언어 연결·분류를 사용했다. 개별 URL과 확인 시각은 사전 및 감사 기록에 보관했다.
- 공식 페이지 다운로드로 확인한 근거와, 기존 수집 설명에서 확인한 근거를 구분했다. 모든 상품 상세 페이지를 새로 방문한 것은 아니다.
- 1차 상품 5,486개 반영, 추가 검증 116개 반영, 실패 0건. 116개에는 기존 상품의 보완이 포함되며 서로 더한 값은 고유 상품 수가 아니다. 이번 근거 패치 대상 고유 상품은 5,515개다.
- 기존 상품 원문·사용자 한국어 상품명·구매·즐겨찾기·이미지는 변경하지 않았다. 이번 단계는 분류 작업으로, 전체 상품명 번역 완료를 의미하지 않는다.
- 프라이즈 피규어는 유통·제품군 분류이며 스케일 또는 가동 여부를 보장하지 않는다. 완성품·논스케일 등의 보수적 분류도 별도로 제공한다.
- 수동 확인값은 이후 자동 모델 결과보다 우선한다. 원문 해시가 바뀌면 이전 결정을 강제 적용하지 않는다.
- 로컬 분류 워커에는 검증 사전을 연결했다. 워커 프로필은 현재 실행하지 않았으며, 새로운 인터넷 자동 조사나 유료 API 호출은 수행하지 않는다. 모델 추가 학습을 완료했다는 의미도 아니다.

## 직접 기입하는 방법

[문서 안내](../reviews/classification_20261111/README.md)에서 작품·캐릭터·종류 파일을 열고 JSON 블록의 `value`를 입력한 뒤 `approved`를 `true`로 변경한다. 모르면 그대로 두고, 해당 없음이 확실한 경우에만 `not_applicable`을 사용한다. 문서의 생성·가져오기 도구와 DB 미리보기·반영 명령은 안내 파일에 있다.
