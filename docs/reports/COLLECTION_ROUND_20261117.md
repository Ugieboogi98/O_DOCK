## 실행 및 재개

제조사 수집 실행 시 기본적으로 국내 4개 유통사도 포함된다:

```powershell
docker compose run --rm --no-deps backend python -m scripts.collect_new_manufacturers --report-dir /app/media/manufacturer_rounds/NEW_ROUND --commit
```

이 명령은 굿스마일과 핫토이를 제외한다. `NEW_ROUND`는 회차마다 새 경로로 지정한다. 기존 경로는 체크포인트를 재사용한다. 세가의 동적 목록은 이번 회차에서 공식 웹앱 데이터로 확보한 후보 목록을 사용했으며, 위 일반 HTML 탐색만으로 재탐색되지 않을 수 있다.

국내 유통사만 호스트에서 실행:

```powershell
.\.venv\Scripts\python.exe tools/collect_domestic_local.py --latest --commit --limit 20 --report-dir data/private/retail_price/NEW_ROUND
```

같은 보고서 경로로 재실행하면 완료된 유통사는 유지하고 실패한 유통사를 재시도한다. 예약 실행 경로인 `catalog_refresh`에도 국내 수집 단계를 추가했다. 별도의 상시 유통사 워커는 켜지 않았다.

## 서비스 및 검증
