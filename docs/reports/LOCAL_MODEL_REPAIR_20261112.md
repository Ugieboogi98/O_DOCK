# 번역·캐릭터 누락 수정 및 전체 재검증 — 2026-11-12

## 판정

**전체 상품 처리 시도 완료와 전체 번역 완료는 다르다.** 이전 6,161건 배치는 종료됐지만 한국어 상품명이 없는 상품이 1,181개 남아 있었다. 이번에는 모델 프롬프트·이름 추출 후처리·검증기·재실행 캐시를 수정하고 실제 DB와 서비스에 반영했다. 모델 가중치를 새로 학습한 작업은 아니다. 자동 운영의 의미 정확도 기준을 통과했다는 주장도 하지 않는다.

## 원인과 수정

1. 니케 엠마의 원시 모델 응답은 `エマ → 에마`를 캐릭터로 추출하고 있었다. 그러나 `grounded_result`가 사전에 없는 인물을 무조건 지워 최종 분류값이 비었다. 인물 역할을 확인할 수 있는 상품명 구조와 공식 소개문을 사용하고, 한국어 표기는 사전·기존 게시 제목·독음 일치로 대조하도록 수정했다. 미확인 한자 독음이나 그럴듯한 이름만으로는 통과하지 않는다.
2. 기존 `korean()`의 가타카나 범위가 가운데점 `・`도 일본어 글자로 분류했다. 이미 한글인 `한텐구・조하쿠텐・굣코` 같은 제목이 거절됐다. 실제 일본어 문자와 문장부호를 구분했다. 관련 448개 상품을 재검증했다.
3. 이미 한국어인 상품명도 라틴 브랜드가 사전에 없으면 비워 버리는 경우가 있었다. 한국어 원문은 숫자·축척 등 기존 검사를 거쳐 그대로 보존한다.
4. 같은 모델 태그와 상품 원문만 같으면 `--refresh-local`도 예전 완료 보고서를 재사용했다. 프롬프트·사전·추출 및 검증 코드의 fingerprint를 확인하도록 수정했다. 정책 변경 후 같은 보고서 폴더에서 다시 실행해도 예전 결과를 완료로 건너뛰지 않는다.

가나 유사도만으로 통과시키는 초기 안에서는 잘못된 독음이 발견돼 **저장 전에 폐기**했다. 작은 가나 구분, 기존 게시 제목 대조, 작품명·전함 오인 차단을 보완한 뒤 반영했다. 기존 한국어 제목 4,923개를 대조 자료로 동결했지만 사람 검수 gold나 공식 표기 인증으로 취급하지 않는다.
