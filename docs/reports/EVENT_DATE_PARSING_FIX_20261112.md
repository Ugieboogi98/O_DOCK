# 행사 월·일 일정 표시 수정

2026-11-12 14:54 KST. 사용자가 지적한 `🗓️ 11/19(목)~12/2(수)`가 일정 미확인으로 표시된 문제를 수정하고 실제 DB·API·프런트엔드에 반영했다.

문제 원인은 연도 없는 기간을 전부 null 처리하고 UI가 남아 있는 원문 월·일도 버렸기 때문이다. 해당 AK PLAZA 공식 공지는 게시 시각이 2026-11-09이며, 함께 수집한 anique.jp 공식 공지에는 `2026년 11월 19일(목)~12월 2일(수)`로 명시되어 있다. 실제 게시물의 연도·요일이 일치함을 대조했다.

일반 추출은 본문 연도를 우선하고, 연도가 없는 경우 수집을 실행한 오늘 날짜가 아니라 게시 시각에 가까운 연도를 기준으로 보완한다. 게시 전후 183일 안의 시작일, 183일 이하 기간, 명시 요일 일치, 연말 전환을 검사하고 근거·게시 시각·year_inferred를 저장한다. 연도가 불확실하거나 여러 기간·장소가 섞이면 확정 날짜를 만들지 않고 원문 일정은 보존해 화면에 표시한다. 예약·예매·판매 기간은 행사 기간으로 채택하지 않는다. 보완 연도는 상세 화면에 안내한다.

기존 30건을 추가 API 호출 없이 재해석했다. 원본 게시물·이미지는 유지하고 event_candidates의 날짜·근거만 갱신했다. 결과는 `data/private/instagram/20261112_1454_dates/`에 있다. 새 수집과 원문 재검사 CLI도 게시 시각을 전달하도록 수정했다.

배포 후 실제 `http://localhost:8080/api/events` 응답에서 문제 공지가 다음과 같이 확인됐다.

```json
{
  "start_date": "2026-11-19",
  "end_date": "2026-12-02",
  "period": "UPCOMING",
  "period_text": "11/19(목)~ 12/2(수)",
  "year_inferred": true
}
```
