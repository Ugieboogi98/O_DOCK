# 행사 중복·분류·종료 처리 수정 (2026-11-12)

## 적용 기준

- 원본 게시물 ID가 같으면 갱신하며 새 행을 추가하지 않는다.
- 서로 다른 게시물도 작품·행사 유형·기간·장소가 일치하면 목록에서 한 행사로 묶는다. 원본 공지와 이미지는 해당 행사에 함께 보존한다.
- `홍대점/홍대`, `2F/2층`, `플라자/PLAZA` 등의 장소 표기 차이를 정규화한다. 서로 다른 층·기간은 구분한다. 판단에 필요한 작품·기간·장소가 없으면 임의로 합치지 않는다.
- 행사명에 `진격의 거인展/전`처럼 전시가 명시되면 본문의 팝업 표현보다 전시회 분류를 우선한다.
- 최초 수집일(한국 날짜)보다 종료일이 이전인 행사는 신규 저장·노출에서 제외한다. 기존 데이터의 기준일은 2026-11-12이며, 이후 신규 수집은 실제 최초 수집일을 사용한다. 종료 당일은 포함한다.
- 수집 당시 예정·운영 중이던 행사는 보존하고, API 조회 시 한국 날짜로 상태를 계산해 종료일 다음 날부터 `ENDED`로 표시한다. 최초 수집 시각은 `source_posts.raw_payload.first_collected_at`에 보존한다.
- 여러 명시적 기간과 장소가 있는 공지는 각각의 값을 유지한다. 모든 기간이 끝났을 때 종료로 처리한다. 종료일을 알 수 없는 행사는 추측으로 제외하지 않는다.
