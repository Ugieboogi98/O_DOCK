# v2 검증

- Vue production build 성공, 프론트 유틸리티 테스트 2개 통과.
- 백엔드 테스트 39개 통과. 구매 CRUD/배송상태/입력값 검증, 관심상품 멱등성, 이미지 중복 저장, 환산 계산, 공식 한국 URL 제한 포함.
- PostgreSQL 호환 PGlite 18.6에서 초기 마이그레이션 → 114개 시드 → v2 마이그레이션 순서 검증.
- 실제 굿스마일 상품 HTML에서 갤러리 주소를 추출하고 대표 이미지 1장을 실제 다운로드하여 상세 API/이미지 제공 경로 확인 (결과는 verification-v2.json).

## 외부 서비스 한계

- 사용자 OpenAI 키는 사용하지 않았고 유료 번역 호출을 실행하지 않았습니다. 번역 호출은 설치 후 사용자의 명령으로 실행됩니다.
- 반다이남코코리아몰 자동 조회는 이 환경에서 HTTP 접속 실패. 구조화 데이터 파서와 공식 URL/동일 상품 확인 입력 흐름을 구현했지만 실제 사이트 모든 상품의 자동 가격 추출을 보장하지 않습니다. 수동 공식 가격 등록이 제공됩니다.
- 코토부키야는 사용자 로그에서 Cloudflare challenge가 확인되어 수집 비활성화. 우회 기능 없음.
- 모든 제조사 이미지 선택자를 실사이트에서 전수 검증하지 않았습니다. OG 이미지, Product JSON-LD, 상품 갤러리 후보를 사용하며 결과가 없으면 기존 이미지를 유지합니다.
- Docker 엔진 전체 실행과 실제 브라우저 클릭 테스트는 이 환경에서 수행하지 않았습니다. Vue 빌드와 API 통합 테스트로 검증했습니다.
- 별도 다중 사용자 인증/외부 공개 운영 지원 없음. 기본 포트는 localhost에 바인딩됩니다.

## 참고 원문

- 환율 API: https://frankfurter.dev/ (v2 JPY/KRW, 키 없음, 일별 데이터)
- 한국 공식 판매처: https://www.bnkrmall.co.kr/main/figure_index.do

실제 이미지 통합 검사에서는 실행 환경의 프록시 DNS 제약으로 검증 스크립트에 한해 고정 굿스마일 도메인 검사로 대체했습니다. 배포 코드의 공개 IP/HTTPS 검사는 그대로 유지되며, 이 환경에서 해당 DNS 사전검사까지 실네트워크 통과했다고 주장하지 않습니다.
