# O_DOCK 디자인 시스템

최신 요청에 따라 화이트·스카이블루 테마를 적용했다. 밝은 하늘색은 버튼 배경과 선택 표시에, 진한 청색은 포인트 글씨와 키보드 포커스에 사용한다.

실행 기준 파일: `frontend/src/design-system.css`. 기존 레이아웃 스타일은 유지하고 중복 하드코딩 색상을 토큰 참조로 치환했다. 프레임워크와 UI 의존성은 유지한다.

| 역할 | 토큰 / 값 |
|---|---|
| 화면 | --bg / #ffffff |
| 표면 | --surface / #f6f9fc |
| 내부 표면 | --surface-soft / #f0f6fa |
| 선택·부각 | --surface-raised / #eaf4fb |
| 본문 | --ink / #172b3a |
| 보조 | --muted / #526777 |
| 메타 | --subtle / #5b7080 |
| 경계 | --border / #d6e2eb |
| 포인트 | --accent / #7dd3fc |
| 포인트 글씨 | --accent-ink / #03698f |
| 포인트 위 글씨 | --on-accent / #123449 |

상품 이미지 영역의 #f5f7f9은 사진용 배경이다. multiply 혼합을 없애 실제 이미지 색상을 보존한다. 이미지 내부의 글씨와 브랜드 색은 변경하지 않는다.

폰트는 Apple SD Gothic Neo → Apple SD Gothic → 시스템 UI → Malgun Gothic → sans-serif. 본문 15px, UI 14px, 메타 12–13px, 카드 제목 14–16px, 섹션 23–28px, 주요 제목 28–44px. 일반 가중치 400–500, 강조는 600. 숫자는 tabular-nums를 사용한다.

간격은 4/8/12/16/24/32/48/64px. 데스크톱 콘텐츠 최대 1440px, 좌우 48px, 태블릿 32px, 모바일 20px. 컨트롤 반경 6px, 카드 8px. 표면 차이와 경계로 깊이를 표현하고 장식 그림자는 줄인다.

주요 레이아웃 전환: 1600/1100/800/600px. 검증 너비는 375/430/768/1280/1440/1920px. 모바일 메뉴는 펼침 상태를 aria-expanded로 전달하고 기존 모든 링크를 제공한다. 목록은 모바일 2열, 데스크톱 3–4열을 사용한다.

일반 전환은 180ms cubic-bezier(.2,.7,.2,1). 무의미한 이동·확대는 제거하고 기존 슬라이더의 일시정지·포커스·reduced-motion 처리를 유지한다. 포커스는 오렌지 2px, 바깥 간격 4px. 주요 컨트롤 목표 크기는 44px 이상이다.

대비 목표는 WCAG 2.2 AA. 주요 본문·보조 글씨·포인트 버튼을 수치 확인하고 전체 준수 인증과는 구분한다. 로그인·관심상품·구매 등 업무 로직, 외부 링크, 가격 정책은 변경하지 않는다.
