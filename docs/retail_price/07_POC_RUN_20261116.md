# 매니아하우스 소량 실행 결과

사용자의 후속 ‘확인하고 실행해’ 요청에 따라 공개 상품 5건을 대상으로 일회성 dry-run을 구현하고 2026-11-16 오전 10시 39분 실행했다. 이 요청의 실행 범위는 소량 기술 검증으로 해석했다. 판매처의 서비스 재이용 허가 상태는 `REQUIRES_PERMISSION_FOR_SERVICE_REUSE`로 보고서에 명시했다.

## 실제 결과

목록 1페이지와 상품 상세 5개 조회가 완료됐다. 파싱 5/5, 유효 체크디지트 JAN 확보 5/5, 전체 판매가 추출 5/5, 오류 0건이다. 표본 모두 예약상품이며, 표시 판매가와 구조화된 전액결제 가격을 대조했다. 독립 정답 데이터에 대한 일반 정확도는 측정하지 않았다. 실제 품절·할인·JAN 누락 표본은 이번 목록에서 확보하지 못했다.

| 판매처 상품 ID | 상품 | 전액 판매가 KRW | 상태 | JAN |
|---|---|---:|---|---|
| 26647 | 시로유키히메 통상판 | 298,000 | PREORDER | 6979272331096 |
| 26646 | 시로유키히메 디럭스판 | 318,000 | PREORDER | 6979272331102 |
| 26619 | HL-02 해령 베타버전 | 53,000 | PREORDER | 6976816650132 |
| 26618 | HL-01 해령 스탠다드타입 | 65,000 | PREORDER | 6976816650125 |
| 26617 | POP ELEVATED BOOST 원피스 나미 | 221,000 | PREORDER | 4535123716737 |

기존 카탈로그의 동일 JAN 후보는 0/5였다. 자동 매칭 확정은 0/5이며 다른 상품에 연결한 행도 0건이다. DB는 후보 조회에만 사용했다. 결과는 `data/private/retail_price/20261116_maniahouse_poc/preview.json`에 저장했다.

## 구현

- `backend/app/collectors/retailers/maniahouse.py`에서 Cafe24 상세의 라벨별 사실 정보와 ProductGroup/hasVariant 결제 옵션을 읽는다.
- 전체 가격 선택은 명시적 전액결제 옵션을 우선한다. 예약금·잔금·여러 옵션의 최저가를 전체 가격으로 선택하지 않는다. 표시가 충돌은 NULL과 경고로 남긴다.
- 판매처 내부 SKU와 제조사 모델번호를 별도 취급하며, 짧은 제목 숫자를 JAN으로 사용하지 않는다.
- `backend/scripts/preview_domestic_prices.py`는 `--execute`를 명시한 최대 5개 일회성 미리보기다. 설정 파일의 판매처 활성화를 변경하지 않고 실행 인스턴스의 제한된 상품 경로만 조회한다.
- 기존 SafeFetcher의 공개 DNS·호스트·경로·robots·지연 검사를 재사용한다. 요청 간격은 최소 3초, 타임아웃 15초, 본문 3MB 제한이다. 403·429·리디렉션·접근 확인 화면을 만나면 재시도 없이 결과를 기록하고 종료한다.
- 중간 결과를 원자적으로 기록해 실패 전 성공한 표본을 보존한다. 원본 HTML·이미지·쿠키는 보고서에 보관하지 않는다.
- JAN 후보만 제시하고 판본·특전 확인이 필요한 연결은 검토 상태로 표시한다. 수집 CLI에는 DB 저장 경로가 없다.

## 재현 명령

현재 backend 이미지에 코드를 배포하지 않아 호스트의 수정 코드만 일회성 컨테이너에 연결했다. 보고서 디렉터리는 매 실행 새 이름을 사용한다.

```powershell
docker compose run --rm --no-deps -v "${PWD}/backend/app:/app/app:ro" -v "${PWD}/backend/scripts:/app/scripts:ro" -v "${PWD}/data/private/retail_price:/retail-reports" backend python -m scripts.preview_domestic_prices --execute --limit 5 --report-dir /retail-reports/<새로운_실행명>
```

## 검증과 남은 범위

`backend/tests/test_maniahouse_preview.py`에 예약금·잔금·전액 가격 선택, 옵션 범위, 품절 우선, 정가, 가격 충돌, JAN 검증, URL 별칭과 외부 호스트, 403·429·리디렉션 즉시 종료를 검증하는 8개 테스트를 추가했다. 기존 `test_quality.py` 13개와 함께 21개가 통과했다.

이번 실행은 국내 판매처 기능의 첫 실제 표본 검증이다. 피규어프레소 상세는 앞선 접근 제한 관측 이후 실행하지 않았다. listing/offer 마이그레이션, 운영 저장, 상품 상세의 가격 표시 연동, 정기 수집은 후속 구현 범위다. 운영 연동 전에 제조사별 JAN 커버리지와 판본·특전·가격 조건 검증 및 판매처 이용 범위를 확인해야 한다.
