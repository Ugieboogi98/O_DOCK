# 판매처 제휴 문의 초안

외부 발송 전 초안이다. 매니아하우스는 공개 일반 문의 경로, 피규어프레소는 도매문의·고객센터를 통해 데이터 제휴 담당 부서를 확인한다.

## 문의 문안

제목은 ‘O_DOCK 상품 가격·판매 상태 정보 연동 및 이용 범위 문의’로 제안한다.

안녕하세요. 피규어·서브컬처 상품 정보를 제공하는 O_DOCK 프로젝트에서 국내 판매처의 상품 구매 안내 연동을 검토하고 있습니다.

귀사의 공개 상품명, 제조사, JAN 또는 제조사 모델번호, 일반 공개 판매가, 판매 상태, 원본 상품 URL, 마지막 확인 시각을 기존 제조사 상품 카탈로그와 연결하고자 합니다. 사용자에게 판매처와 구매 링크를 표시하고 귀사 원본 상품 페이지로 안내하는 용도입니다.

아래 항목에 대해 가능한 이용 범위와 조건을 안내 부탁드립니다.

1. 공식 API·CSV·제휴 피드 제공 여부와 인증·사용 신청 방법
2. 피드 제공이 어려운 경우 허용 가능한 공개 페이지와 요청 간격·최대 건수·업데이트 주기
3. 위 사실 정보의 저장 및 서비스 내 가격 비교·상업적 표시 허용 여부
4. 예약금·잔금·샵특전·옵션·쿠폰 및 회원가의 구분 기준과 상품 식별자 제공 가능 여부
5. 출처 표기, 링크 형식, 정보 보관 기간, 수정·삭제 요청 처리 조건
6. 협의 가능한 연락 창구 및 허가 범위를 남길 수 있는 문서·이메일 절차

초기 검증 범위는 목록 1페이지와 상품 상세 최대 5개이며, 정기 수집 주기와 서비스 표시 범위는 협의 후 정하고자 합니다. 검토에 필요한 서비스 설명이나 데이터 항목 명세가 있다면 전달드리겠습니다. 감사합니다.
