# 구현 구조와 RAG 설계

## 서비스 경계

Vue 3 (Vue Router + Pinia + Tailwind/CSS) → FastAPI → PostgreSQL / ChromaDB.
Nginx는 Vue 정적 파일과 `/api/` 프록시를 제공합니다. API 키는 백엔드 환경 변수만 읽습니다.

PostgreSQL의 14개 테이블은 제조사·제품 라인·제품·버전·공식 가격·판매처·공식성 검증·신품 가격 관측·중고 플랫폼·중고 매물·이미지 권리·문서·수집 작업·검색 이력을 분리합니다.
금액은 NUMERIC(14,2), 시간은 timezone-aware, 원문 URL 및 가격 종류를 별도로 보존합니다.

## 두 벡터 컬렉션

| 컬렉션 | ID | 내용 |
|---|---|---|
| figure_metadata | figure_id:variant_id | 제품별 전체 정형 메타데이터 |
| figure_documents | figure_id:variant_id:doc_id:chunk_index | 해당 제품의 공식 사실 발췌 및 추가 수집 문서 |

모든 청크에 제품/버전/출처 유형/제목/URL/수집 시각을 기록합니다.
메타데이터 청크는 ID로 조회해 무조건 근거 맨 앞에 넣습니다. 색인이 없으면 현재 PostgreSQL 필드로 대체하고 경고합니다.
외부 문서는 variant_id로 필터링하여 임베딩 유사도 검색하고 SHA-256 본문 중복을 제거합니다.

- 기본 청크 크기 1000자, overlap 200자: 제품 사양 문맥을 크게 자르지 않되 중복을 과도하게 늘리지 않는 시작값.
- Top-k 5: 외부 청크 수이며 메타데이터 1건은 별도 포함. UI에서 1~15 변경 가능.
- fetch_k 20: MMR 후보 풀. lambda=0.65로 관련성에 더 큰 비중을 둡니다.
- 현재 초기 발췌 문서들은 짧아 제품당 대부분 1청크입니다. 길이 변화와 stale chunk 삭제는 테스트로 확인했습니다.
- 임베딩 모델 서명이 바뀌면 재색인을 요구합니다. 컬렉션에 차원이 같은 다른 모델을 섞지 않습니다.
- upsert를 먼저 완료한 후 이전 청크 꼬리를 삭제합니다. 실패한 임베딩 때문에 기존 색인을 먼저 잃지 않습니다.

## LangGraph

`START → retrieve → generate → END`

retrieve: 선택 제품 메타데이터 + 필터링된 문서 청크 + 필요한 경우 가격 관측 근거.
generate: 근거·질문·제한된 대화 이력을 LLM에 전달. 키가 없으면 높이/재질/제조사/스케일/발매일만 정형 조회.
대화 이력은 사실의 근거로 취급하지 않습니다. 외부 문서의 지시는 따르지 않도록 프롬프트에서 분리합니다.

## 세 프롬프트

1. QUERY_PROMPT: 도메인 전문가 역할, 한국어/일본어/영어 검색어 JSON. 원문 제품명은 항상 추가.
2. SELECT_PROMPT: 제목·요약 기반 관련 후보 ID JSON. 선택 제품 공식 문서는 선별 결과와 무관하게 추가.
3. ANSWER_PROMPT: 근거에서만 한국어 답변, 주요 주장 `[근거 N]`, 정보가 없으면 확인되지 않음.

프롬프트 원문은 `backend/app/rag/prompts.py`. 검색 API는 문서 발견용입니다. 검색 요약만 보고 가격을 확정하지 않습니다.
수집은 관리 UI의 명시적 요청으로 실행하여 기본 채팅마다 불필요한 외부 비용이 발생하지 않습니다.
완료된 검색어는 DB SearchRun 캐시를 재사용합니다. 원문 본문은 허용된 출처만 수집합니다.

## 인용

서버는 `[근거 N]`의 실제 사용 번호만 파싱해 제목/원문 URL과 함께 반환합니다.
범위를 벗어난 번호가 있으면 답변을 거절합니다. 인용이 없는 사실 답변도 표시하지 않습니다.
이 검증은 번호 무결성 검증입니다. 모델의 문장과 원문 사이의 의미적 일치까지 완벽히 보장하지 않으므로 실제 API 평가가 별도로 필요합니다.

## 가격과 매칭

안정적인 SKU/JAN 일치가 필요하고 제조사/스케일/버전 충돌 및 세트 상품은 거절합니다.
식별자가 부족하면 MATCH_REVIEW_REQUIRED로 저장하고 최저가/중앙값 집계에서 제외합니다.
동일 매물 URL은 최신 관측만 사용하고, 최근 168시간을 벗어난 가격은 현재 집계에서 제외합니다.
중고는 플랫폼·원통화·상품 상태·판매 상태별로 나누고 표본 3개 미만이면 중앙값을 보류합니다.

## 기본 기능과 확장 경계

자연어 검색은 규칙 또는 LLM으로 조건을 구조화한 뒤 SQL 정확 필터를 적용합니다.
지원하지 않는 가격/색상 조건은 무시하지 않고 안내합니다. 임의의 모든 자연어 조건을 지원하는 범용 검색기는 아닙니다.
PDF/TXT 추가 자료는 `scripts.import_document`로 페이지별 출처를 기록하며 같은 두 번째 컬렉션에 색인합니다.
복수 출처 및 의미 검색의 품질은 실제 자료·임베딩 모델·사용자 API 환경에서 평가해야 합니다.
